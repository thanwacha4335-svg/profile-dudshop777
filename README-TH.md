# DUDSHOP777 Profile

MYNAME IS DUDSHOP777

## วิธีแก้ไขข้อมูล
เปิดไฟล์ `app/page.tsx`
- แก้ข้อความแนะนำตัวในส่วน ABOUT
- แก้ลิงก์ Discord / Facebook / Instagram ในตัวแปร `links`
- ลิงก์ร้านค้าปัจจุบันแยกไว้แล้ว

## วิธีเปิดโปรเจกต์
ต้องใช้ Node.js 18.18 ขึ้นไป:
```bash
npm install
npm run dev
```

## Deploy
นำโฟลเดอร์นี้ขึ้น GitHub เป็น repository ใหม่ จากนั้นนำ repository ใหม่นี้ไป Import ใน Vercel
ตั้งชื่อโปรเจกต์เป็น `profile-dudshop777` แล้วตรวจสอบการตั้งค่าโดเมน `profile-dudshop777.vercel.app`
ชื่อโดเมนจะใช้ได้ก็ต่อเมื่อยังว่างและบัญชี Vercel อนุญาตให้ใช้
